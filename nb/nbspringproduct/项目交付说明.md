# 农宝后台管理系统 - 项目交付说明

## 📋 项目概述

本项目是基于Spring Boot开发的农宝后台管理系统，为前端Vue项目提供完整的RESTful API接口服务。

### 项目信息
- **项目名称**: 农宝后台管理系统 (nbspringproduct)
- **技术栈**: Spring Boot 2.6.13 + MyBatis-Plus 3.4.3 + MySQL 8.0
- **开发语言**: Java 1.8
- **构建工具**: Maven
- **服务端口**: 80

## 🚀 快速启动步骤

### 第一步：配置数据库
```bash
# 1. 创建数据库并执行脚本
mysql -u root -p < src/main/resources/sql/schema.sql

# 2. 修改数据库连接配置
# 编辑 src/main/resources/application.yml
# 修改 username 和 password 为你的数据库账号密码
```

### 第二步：启动后端
```bash
# 进入项目目录
cd nbspringproduct

# 编译并启动
mvn clean spring-boot:run
```

### 第三步：验证接口
访问测试接口验证启动成功：
```
http://localhost:80/dev-api/test/user/list
```

### 第四步：启动前端（可选）
```bash
cd ../nbvueproject
npm install
npm run dev
```

## ⚠️ 注意事项

1. **数据库连接**：首次运行前必须创建数据库并执行初始化脚本
2. **端口占用**：如果80端口被占用，请修改配置文件中的端口
3. **编码问题**：确保数据库和项目统一使用UTF-8编码
4. **JDK版本**：必须使用JDK 1.8或以上版本
5. **Maven配置**：如果依赖下载慢，建议配置阿里云Maven镜像
