# 农宝后台管理系统 - 启动指南

## 一、环境准备

### 1.1 所需软件
- **JDK**: 1.8 或以上版本
- **Maven**: 3.6+ 
- **MySQL**: 8.0+
- **开发工具**: IntelliJ IDEA (推荐) 或 Eclipse

### 1.2 检查环境
```bash
# 检查JDK版本
java -version

# 检查Maven版本
mvn -version

# 检查MySQL版本
mysql --version
```

## 二、数据库配置

### 2.1 创建数据库
1. 登录MySQL数据库：
```bash
mysql -u root -p
```

2. 执行数据库初始化脚本：
```bash
# 在项目根目录执行
mysql -u root -p < src/main/resources/sql/schema.sql
```

或者手动创建：
```sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS nb_database DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 使用数据库
USE nb_database;

-- 执行 schema.sql 中的建表语句
```

### 2.2 修改数据库连接
编辑 `src/main/resources/application.yml` 文件：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/nb_database?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=false&serverTimezone=GMT%2B8&allowPublicKeyRetrieval=true
    username: root      # 修改为你的数据库用户名
    password: root      # 修改为你的数据库密码
```

## 三、项目启动

### 3.1 使用Maven命令启动

#### 方式一：命令行启动
```bash
# 进入项目目录
cd nbspringproduct

# 清理并编译
mvn clean install

# 启动项目
mvn spring-boot:run
```

#### 方式二：打包后运行
```bash
# 打包项目
mvn clean package

# 运行jar包
java -jar target/nbspringproduct-0.0.1-SNAPSHOT.jar
```

### 3.2 使用IDEA启动
1. 用IDEA打开项目
2. 等待Maven依赖下载完成
3. 找到主启动类 `NbspringproductApplication.java`
4. 右键选择 `Run 'NbspringproductApplication'`

### 3.3 验证启动成功
看到以下日志说明启动成功：
```
Started NbspringproductApplication in X.XXX seconds
```

访问测试接口：
```
http://localhost:80/dev-api/test/user/list
```

## 五、前后端联调

### 5.1 启动前端项目
```bash

cd ../nbvueproject

# 安装依赖
npm install

# 启动开发服务器

```

### 5.2 配置前端代理
前端项目已配置跨域支持，可直接调用后端接口。

如果需要配置代理，修改 `vite.config.ts`：
```typescript
export default defineConfig({
  server: {
    proxy: {
      '/dev-api': {
        target: 'http://localhost:80',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/dev-api/, '')
      }
    }
  }
})
```

## 六、常见问题

### 6.1 端口被占用
**问题**：启动时提示端口80被占用

**解决**：修改 `application.yml` 中的端口配置
```yaml
server:
  port: 8080  # 改为其他端口
```

### 6.2 数据库连接失败
**问题**：启动时报数据库连接错误

**解决方案**：
1. 检查MySQL服务是否启动
2. 检查数据库名、用户名、密码是否正确
3. 检查数据库是否已创建
4. 检查MySQL端口是否为3306

### 6.3 依赖下载失败
**问题**：Maven依赖下载失败

**解决方案**：
1. 配置Maven镜像（阿里云）
2. 编辑 `~/.m2/settings.xml`：
```xml
<mirrors>
  <mirror>
    <id>aliyunmaven</id>
    <mirrorOf>*</mirrorOf>
    <name>阿里云公共仓库</name>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```

### 6.4 Lombok不生效
**问题**：IDE提示找不到getter/setter方法

**解决方案**：
1. IDEA安装Lombok插件
2. 设置 -> Build -> Compiler -> Annotation Processors -> Enable annotation processing

## 七、开发建议

### 7.1 日志级别调整
开发环境可以开启DEBUG日志，生产环境建议使用INFO或WARN：
```yaml
logging:
  level:
    com.movie.nbspringproduct: info  # debug -> info
```

### 7.2 数据库连接池配置
生产环境建议配置Druid连接池：
```yaml
spring:
  datasource:
    type: com.alibaba.druid.pool.DruidDataSource
    druid:
      initial-size: 5
      min-idle: 5
      max-active: 20
```

### 7.3 接口文档
建议集成Swagger或Knife4j生成API文档，方便前后端对接。
