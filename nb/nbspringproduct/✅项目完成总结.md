## 🚀 快速开始（3步启动）

### 第1步：配置数据库
```bash
# 在MySQL中执行
mysql -u root -p < src/main/resources/sql/schema.sql
```

### 第2步：修改配置
编辑 `src/main/resources/application.yml`：
```yaml
spring:
  datasource:
    username: root      # 改成你的数据库用户名
    password: root      # 改成你的数据库密码
```

### 第3步：启动项目
```bash
cd nbspringproduct
mvn spring-boot:run
```

访问测试：http://localhost:80/dev-api/test/user/list
